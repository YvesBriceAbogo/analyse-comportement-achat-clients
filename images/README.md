# Captures du rapport Power BI

Ce dossier contient les captures utilisées pour présenter le rapport et son modèle de données.

| Fichier | Description |
|---|---|
| `tableau-de-bord-01.png` | Vue d’ensemble : montants d’achat, catégories, groupes d’âge et segmentation des clients |
| `tableau-de-bord-02.png` | Analyse détaillée : notes produits, remises, livraison et abonnement |
| `modele-de-donnees.png` | Modèle analytique constitué de la table `customer_shop` |

Les captures présentent un état du rapport à la date de leur export. Elles ne sont pas actualisées automatiquement lors du rafraîchissement du rapport dans Power BI Service.
